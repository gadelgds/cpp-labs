Правила этого словаря (упрощённый технический стиль ASD-STE100, применён примерно на 60%).
  • Одна мысль — одно предложение.
  • Описание — не больше 25 слов в предложении.
  • Действительный залог: предложение говорит, кто что делает.
  • Одно понятие — одно слово: термин определяется один раз и дальше повторяется без изменений.
  • Первое предложение — ответ (само определение), дальше только детали и пример.
  • Один абзац — одна тема, не больше шести предложений.
Правила действуют на определения. Вступление и примечания написаны обычным языком.
Как читать словарь. Буфер — это кусок памяти, куда программа кладёт данные. Диск — это устройство, где файлы хранятся постоянно (жёсткий диск или SSD). Смещение — это номер байта в файле, с которого начинается чтение. Ядро Windows — это главная часть Windows, которая управляет памятью и дисками. Физическая память — это настоящая память компьютера.

Виртуальная память
Задача №3

Виртуальная память — это адресное пространство программы. Windows даёт каждой программе отдельное адресное пространство. Программа работает только со своим адресным пространством. Windows переводит адреса из адресного пространства в физическую память. Пример: две программы пишут по одному адресу, но Windows даёт каждой свою физическую память.

Выравнивание
Задача №1

Выравнивание — это положение буфера на границе, кратной 4096 байтам. Буфер начинается там, где начинается кусок диска размером 4096 байт. Диск читает и пишет только целые куски по 4096 байт. Программа ставит буфер так, чтобы начало буфера совпадало с началом куска. Пример: книга начинается с новой страницы, а не с середины страницы.

Гранулярность распределения
Задача №2

Гранулярность распределения — это шаг, с которым Windows даёт адреса. Шаг равен 64 КБ. Windows даёт начало участка только на границе этого шага. Программа не может начать участок в середине шага. Пример: забор ставят только по столбам, а не между столбами.

Небуферизированный ввод-вывод
Задача №1

Небуферизированный ввод-вывод — это чтение и запись файла мимо системного кэша. Диск передаёт данные прямо в буфер программы. Диск не кладёт данные в системный кэш. Windows не хранит копию данных в системном кэше. Пример: покупатель берёт товар прямо со склада, а не с полки магазина.

Ошибка 87 (ERROR_INVALID_PARAMETER)
Задача №1

Ошибка 87 — это ответ Windows: параметры вызова неверны. Windows возвращает ошибку 87, когда буфер, смещение или размер не кратны 4096. Программа получает ошибку 87 и не читает данные. Программа исправляет параметры и повторяет чтение. Пример: замок не открывается, потому что ключ не подходит к замку.

Проецирование файла в память
Задача №2

Проецирование файла в память — это способ работать с файлом как со страницами памяти. Windows показывает файл как часть адресного пространства программы. Программа читает файл и пишет в файл, как в страницы памяти. Программа не просит Windows читать файл и писать файл. Пример: книга лежит открытой на столе, и читатель берёт любую страницу сразу.

Сброс TLB
Задача №2

Сброс TLB — это очистка маленького кэша в процессоре. Этот кэш хранит переводы адресов в физическую память. Процессор использует переводы адресов, чтобы быстро находить физическую память. Windows очищает этот кэш, когда меняет адреса программы. После очистки процессор ищет переводы адресов заново, и работа замедляется. Пример: учитель стирает шпаргалку с доски, и ученики пишут её заново.

Сектор
Задача №1

Сектор — это самый маленький кусок диска, который диск читает за один раз. Размер сектора равен 4096 байтам. Диск не читает меньше одного сектора. Программа просит у диска целое число секторов. Пример: кирпич — самая маленькая часть стены, и стену строят только из целых кирпичей.

Системный кэш
Задачи №1, №2

Системный кэш — это физическая память, где Windows хранит копии данных из файлов. Windows читает файл с диска один раз и кладёт копию в системный кэш. Программа берёт данные из системного кэша, а не с диска. Второе чтение файла идёт быстрее первого чтения. Пример: повар держит нож под рукой, а не ходит за ним на склад.

Страница памяти
Задачи №1–№3

Страница памяти — это кусок физической памяти размером 4096 байт. Windows делит физическую память на страницы памяти. Windows даёт программе физическую память только целыми страницами памяти. Программа не получает меньше одной страницы памяти. Пример: тетрадь состоит из листов, и продавец продаёт только целые листы.

СУБД
Задача №2

СУБД — это программа для хранения данных и поиска данных. СУБД хранит данные в файлах на диске. СУБД читает из файлов только нужные данные. СУБД сама решает, какие данные держать в физической памяти. Пример: библиотекарь хранит книги и находит нужную книгу без перебора всех книг.

TLB
Задача №2

TLB — это маленький кэш в процессоре для переводов адресов. TLB хранит переводы адресов в физическую память. Процессор берёт перевод адресов из TLB и сразу находит физическую память. Без перевода адресов процессор ищет адрес дольше. Пример: телефонная книга хранит номера, и человек звонит сразу, без поиска номера.

VirtualAlloc
Задачи №1, №3

VirtualAlloc — это функция Windows, которая просит страницы памяти у ядра Windows. Программа вызывает VirtualAlloc, и ядро Windows даёт ей страницы памяти. Ядро Windows даёт адрес, кратный 64 КБ. Программа возвращает страницы памяти ядру Windows, когда они больше не нужны. Пример: человек берёт в аренду склад, а потом возвращает склад хозяину.

FILE_FLAG_NO_BUFFERING
Задача №1

FILE_FLAG_NO_BUFFERING — это флаг для открытия файла без системного кэша. Программа передаёт флаг, когда открывает файл. Флаг говорит Windows: не клади данные в системный кэш. Флаг требует выравнивания буфера, смещения и размера на 4096. Пример: курьер везёт посылку прямо покупателю, а не на склад.

MEM_COMMIT
Задачи №1, №3

MEM_COMMIT — это флаг для выделения страниц памяти. Программа передаёт флаг функции VirtualAlloc. Флаг говорит ядру Windows: дай страницы памяти. Без флага программа получает только адреса, а не страницы памяти. Пример: хозяин не только бронирует стол, но и ставит на стол еду.

MEM_RESERVE
Задачи №1, №3

MEM_RESERVE — это флаг для бронирования адресного пространства. Программа передаёт флаг функции VirtualAlloc. Флаг говорит ядру Windows: сохрани эти адреса за мной. Флаг не даёт страницы памяти, только адреса. Пример: человек бронирует стол в кафе, но еда на столе ещё не стоит.

QueryPerformanceCounter
Задачи №1, №2

QueryPerformanceCounter — это функция Windows для точного замера времени. Программа вызывает функцию до работы и после работы. Функция возвращает число отметок точного таймера Windows. Программа делит разницу отметок на частоту таймера и получает время в миллисекундах. Пример: судья включает секундомер на старте и выключает секундомер на финише.
