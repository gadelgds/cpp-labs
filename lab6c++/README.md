> **Мобильная веб-шпаргалка**: откройте [`index.html`](index.html) — тот же стиль, что в лабах 4–5: код с кнопками копирования, полный построчный разбор каждой программы (ни одна строка не пропущена) и блоки «Как запустить».

> **Словарь терминов**: [`glossary.html`](glossary.html) — обычный словарь: 16 терминов простыми словами с аналогиями из жизни. [`glossary_ste.html`](glossary_ste.html) — тот же словарь в стиле ASD-STE100: одна мысль — одно предложение, не больше 25 слов в описании.

## Условия запуска

### Задание 1 — Блокнот

- Файлов заранее создавать **не нужно**: `notepad.exe` есть в любой Windows.
- Компиляция. MSVC (Developer Command Prompt): `cl /EHsc task1_createprocess_notepad.cpp`. MinGW: `g++ -o task1.exe task1_createprocess_notepad.cpp`.
- Запустить exe из консоли: откроется Блокнот, консоль будет ждать. Закрыть Блокнот — консоль выведет подтверждение и завершится.
- Ожидаемый вывод: строка о запуске с PID процесса и потока → «Ждём, пока вы закроете Блокнот...» → «Блокнот закрыт пользователем.» → «Дескрипторы процесса и потока закрыты (CloseHandle). Ресурсы ядра освобождены.»

### Задание 2 — Parent.exe и Child.exe

- Это **два отдельных exe**: `Parent.exe` и `Child.exe`. Компилируются отдельно:
  - MSVC: `cl /EHsc task2_parent.cpp` (переименовать результат в `Parent.exe`), `cl /EHsc task2_child.cpp` (переименовать в `Child.exe`).
  - MinGW: `g++ -o Parent.exe task2_parent.cpp` и `g++ -o Child.exe task2_child.cpp`.
- **Оба exe должны лежать в ОДНОЙ папке**: Parent запускает Child по относительному имени `L"Child.exe"`. Если Child.exe в другой папке, `CreateProcess` вернёт `FALSE` (обычно код ошибки 2 — `ERROR_FILE_NOT_FOUND`), и Parent завершится с кодом 1.
- Файлов заранее создавать **не нужно**.
- Запуск: запустить `Parent.exe`. Окно Parent покажет установку `STUDENT_ID=19045`, запуск потомка с его PID, перезапись у себя на `99999` и закроется. Окно Child покажет `STUDENT_ID=19045` и фразу, что значение не изменилось вслед за родителем, затем ждёт нажатия клавиши (`system("pause")`).
- **Child.exe можно запустить и отдельно**, без Parent: тогда переменная `STUDENT_ID` в его окружении не задана, и Child выведет ошибку «переменная STUDENT_ID не найдена в блоке окружения» с объяснением, что его запустили напрямую. Это нормальное поведение, а не баг.
- **Предупреждение об ошибке логики**: если Parent перезапишет переменную **ДО** `CreateProcess`, потомок получит уже новое значение `99999`, и доказать автономность будет нечем. Порядок «сначала `CreateProcess`, потом перезапись» — суть задания.
