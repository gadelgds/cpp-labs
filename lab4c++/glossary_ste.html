Как написан этот словарь (стиль STE)

Эта версия написана по правилам ASD-STE100, упрощённого технического английского, перенесённым на русский. Правила применены примерно на 60%: они действуют на сами определения. Вступление, примечания и подписи написаны обычным стилем.

Правила, которые действуют в определениях:

  • Одна мысль — одно предложение.
  • Инструкция — не больше 20 слов. Описание — не больше 25 слов.
  • Действительный залог: предложение называет, кто что делает («Windows показывает», «программа меняет»).
  • Одно понятие — всегда одно и то же слово: файл, программа, Windows, значение, тип, смещение, указатель, память, адрес, байт, число, ошибка, команда. Без синонимов. Падежные формы одного слова допускаются.
  • Сначала ответ, потом подробности: первое предложение — само определение, дальше только детали или пример.
  • Один абзац — одна тема, не больше шести предложений.

Что не применено полностью: русский язык требует падежей, поэтому одно и то же слово встречается в разных падежных формах (файл, файла, файлу) — это считается тем же словом. Английские имена из кода (static_cast, MapViewOfFile, void*) оставлены как есть: это имена, а не слова для замены.

У каждого определения указан подсчёт слов — проверено скриптом, а не на глаз.

Неявное приведение
Задача 1

Неявное приведение меняет тип значения без команды в программе.

Программа сама меняет тип, когда она записывает значение в переменную другого типа.

Пример: программа записывает число 25000 типа int в переменную типа long.

Оно сохраняет значение, но меняет его тип.

Пример: программа меняет тип числа 25000 с int на long.

Проецирование файла в память
Задача 3

Проецирование файла в память показывает файл программе как память.

Windows показывает байты файла, и программа читает байты как ячейки памяти.

Программа не использует отдельные команды чтения.

Задача 2

Разыменование читает значение по адресу.

Указатель хранит адрес, а разыменование берёт значение по этому адресу.

В программе звёздочка показывает разыменование: *ptrInt читает значение.

Расширяющее преобразование
Задача 1

Расширяющее преобразование меняет меньший тип на больший тип.

Оно сохраняет значение точно и не теряет данные.

Пример: программа меняет int на long и float на double.

Смещение (offset)
Задача 3

Смещение — это число байтов от начала файла.

Программа пропускает это число байтов и читает файл с этого места.

Пример: смещение 131072 пропускает 131072 байта.

Программа находит маркер сразу и не читает файл с начала.

Программа всегда считает смещение от начала файла.

Страница памяти
Задача 3

Страница памяти — это кусок памяти размером 4 КБ.

Windows обменивается памятью с диском только целыми страницами.

Windows не носит память по одному байту.

Сужающее преобразование
Задача 1

Сужающее преобразование меняет больший тип на меньший тип.

Оно может потерять часть значения.

Пример: программа меняет double на float и теряет точность.

Пример: программа меняет long на int, и большое число не входит в int.

Задачи 1, 2

Явное приведение меняет тип значения по команде в программе.

Программист пишет команду, и программа меняет тип.

В этой лабораторной работе команда называется static_cast.

Allocation Granularity
Задача 3

Allocation Granularity — это шаг распределения памяти, и он равен 64 КБ.

Windows ставит начала областей памяти только через каждые 64 КБ.

Смещение в MapViewOfFile кратно 64 КБ.

Другое смещение не работает, и Windows возвращает ошибку 1132.

double хранит около 15 точных цифр.

Пример: число 125.75 имеет тип double.

Если программа нуждается в точности, она использует double, а не float.

float

float — это тип дробного числа размером 4 байта.

float хранит около 7 точных цифр.

Пример: число 25.25f имеет тип float.

Если программа нуждается в большей точности, она использует double.

IEEE 754
Задача 1

IEEE 754 — это правило хранения дробных чисел.

Правило хранит знак, сдвиг запятой и значащие цифры числа.

Поэтому Windows хранит число 0.1 как 0.10000000149, а не как 0.1.

MapViewOfFile
Задача 3

MapViewOfFile показывает кусок файла программе как память.

Команда принимает смещение и возвращает указатель на начало куска.

Если смещение неверное, команда возвращает NULL, и Windows запоминает ошибку 1132.

Слов в определении: 27 • Предложений: 3 • Самое длинное: 11 слов
static_cast
Задачи 1, 2

static_cast — это команда явного приведения типов.

Программист пишет static_cast<новый тип>(значение), и программа меняет тип значения.

Пример: static_cast<long>(25000) меняет int на long.

Команда работает до запуска программы и ничего не проверяет во время работы.

void*
Задача 2

void* — это указатель без типа.

Указатель — это переменная, которая хранит адрес ячейки памяти.

void* хранит адрес, но не знает, что лежит по этому адресу.

Программа не читает значение по void* сразу.

Сначала программа приводит void* к нужному типу через static_cast.

Слов в определении: 42 • Предложений: 5 • Самое длинное: 11 слов
x64
Задача 2

x64 — это современный тип процессора и Windows.

В x64 адрес занимает 8 байт, поэтому любой указатель занимает 8 байт.

В старом x86 адрес занимает 4 байта.
