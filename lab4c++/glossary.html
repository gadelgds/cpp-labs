Как пользоваться словарём

Здесь 18 терминов из лабораторной работы №4 — только то, что реально встречается в коде и теории. Термины идут по алфавиту: сначала русские названия, потом английские.

Каждое определение — 1–2 коротких предложения. Там, где помогает, добавлена аналогия из обычной жизни — она помечена словом «Аналогия».

В определениях нет терминов, которых нет в этом же словаре. Одно исключение: слово «указатель» объяснено внутри статьи void* — остальные статьи его просто используют.

У каждого термина указано, в какой задаче он встречается: задача 1 — приведение типов, задача 2 — void* и x64, задача 3 — проецирование файла.

Неявное приведение
Задача 1

Программа сама меняет тип значения, без команды в коде. Это происходит, когда значение записывают в переменную другого типа.

Аналогия: Как кассир, который сам разменивает купюру, без просьбы.
Приведение типов
Задачи 1, 2, 3

Это смена типа значения: одни и те же данные начинают читаться по правилам другого типа. Значение при этом обычно сохраняется, меняется только его тип.

Аналогия: Та же вода, но в другом стакане: объём тот же, а форма другая.
Проецирование файла в память
Задача 3

Windows показывает файл программе так, будто файл — это обычная память. После этого программа читает байты файла как ячейки памяти, без отдельных команд чтения.

Аналогия: Вместо того чтобы ходить в библиотеку за каждой страницей, книгу кладут на твой стол целиком.
Разыменование
Задача 2

Это чтение значения по адресу: указатель говорит, где лежит значение, а разыменование достаёт его. В коде это звёздочка перед указателем: *ptrInt.

Аналогия: Адрес дома — это указатель, а зайти в дом и взять вещь — это разыменование.
Расширяющее преобразование
Задача 1

Это приведение от меньшего типа к большему: значение сохраняется точно, ничего не теряется. Примеры: int → long, float → double.

Аналогия: Перелить воду из маленького стакана в большой — ничего не прольётся.
Смещение (offset)
Задача 3

Это число, которое говорит, сколько байт пропустить от начала файла, прежде чем начать читать: смещение 131072 означает «пропусти 131072 байта и читай оттуда». Оно нужно, чтобы читать огромный файл частями и сразу переходить к нужному месту, не загружая файл целиком.

Аналогия: Номер страницы в книге: «открой книгу на странице 128» вместо «читай с первой страницы».
Страница памяти
Задача 3

Это кусок памяти фиксированного размера — 4 КБ (4096 байт). Windows обменивается памятью с диском только целыми страницами, а не по одному байту.

Аналогия: Грузчики носят коробки, а не по одному стакану.
Сужающее преобразование
Задача 1

Это приведение от большего типа к меньшему: часть значения может потеряться. Примеры: double → float теряет точность, а большое число long может не влезть в int.

Аналогия: Перелить воду из большого стакана в маленький — лишнее прольётся.
Явное приведение
Задачи 1, 2

Это смена типа значения по команде в коде: программист сам пишет, во что превратить значение. В этой лабе такая команда называется static_cast.

Аналогия: Сам просишь кассира разменять купюру.
Allocation Granularity
Задача 3

По-русски — шаг распределения памяти. Это шаг, которым Windows меряет начала областей памяти: 64 КБ (65536 байт). Смещение в MapViewOfFile обязано делиться на 64 КБ без остатка.

Аналогия: Полки в шкафу стоят только через каждые 64 сантиметра — книгу нельзя поставить между полками.
double
Задача 1

Это тип дробного числа: 8 байт и около 15 точных цифр. Пример: 125.75. Если нужна высокая точность — бери double, а не float.

ERROR_MAPPED_ALIGNMENT (ошибка 1132)
Задача 3

Это ошибка Windows: MapViewOfFile отказалась работать, потому что смещение не делится на 64 КБ без остатка. Программа получает код 1132 и печатает его на экран.

Аналогия: Попытка поставить книгу между полками — шкаф отказывается.
float
Задача 1

Это тип дробного числа: 4 байта и около 7 точных цифр. Пример: 25.25f. Если нужно точнее — бери double.

IEEE 754
Задача 1

Это общее правило, по которому все компьютеры хранят дробные числа: знак, порядок (насколько сдвинуть запятую) и значащие цифры. Из-за этого правила число 0.1 хранится неточно — как 0.10000000149.

MapViewOfFile
Задача 3

Это команда Windows: «покажи мне кусок файла как память, начиная со смещения». Она возвращает указатель на начало показанного куска. Если смещение неверное, она возвращает NULL, а Windows запоминает ошибку 1132.

static_cast
Задачи 1, 2

Это команда явного приведения типов: static_cast<новый тип>(значение). Пример: static_cast<long>(25000) превращает int в long. Команда работает до запуска программы и во время работы ничего не проверяет.

void*
Задача 2

Это указатель без типа: он помнит адрес, но не знает, что лежит по этому адресу. Указатель — это переменная, в которой лежит адрес ячейки памяти. По void* нельзя сразу прочитать значение: сначала его приводят к нужному типу через static_cast.

Аналогия: Адрес дома без указания, что в доме, — квартира или магазин.
x64
Задача 2

Это современный тип процессора и Windows. В нём адрес занимает 8 байт, поэтому любой указатель занимает 8 байт. В старом x86 адрес занимал 4 байта.
