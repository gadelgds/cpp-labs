Словарь терминов лабораторной работы №3. Здесь собраны все слова, которые встречаются в задачах про асинхронный ввод-вывод и MFT. Термины идут по алфавиту: сначала латиница, потом кириллица.

Как пользоваться: найди слово в списке ниже или нажми на него здесь: $DATA FSCTL_GET_RETRIEVAL_POINTERS IRP LCN MFT OVERLAPPED Slack VCN Асинхронный вызов Блокировка потока Кластер Логический размер Нерезидентный атрибут Резидентный атрибут Синхронный вызов Смещение Событие (hEvent) Физический размер Экстент (Data Run)

Правило словаря: каждое определение использует только те слова, которые есть в этом же словаре, — ничего непонятного внутри объяснений нет.

$DATAЗадачи 2, 3

$DATA — часть записи MFT, которая хранит данные файла. У маленького файла данные лежат в этой части прямо в MFT, а у большого файла в ней лежит карта кластеров, а данные — на диске.

FSCTL_GET_RETRIEVAL_POINTERSЗадача 2

FSCTL_GET_RETRIEVAL_POINTERS — команда, которой программа спрашивает у Windows, где на диске лежат кластеры файла. Windows отвечает списком экстентов, а если файл резидентный, отвечает ошибкой — у такого файла нет кластеров на диске.

IRPЗадача 4

IRP (I/O Request Packet) — пакет, в котором Windows описывает одну операцию с диском. Когда программа читает файл, Windows создаёт IRP, передаёт его диску, а диск возвращает IRP с результатом.

LCNЗадача 2

LCN (Logical Cluster Number) — номер кластера на диске. Windows нумерует все кластеры тома подряд с нуля, и LCN говорит, где именно на диске лежит кусок файла.

MFTЗадачи 2, 3

MFT (Master File Table) — главная таблица NTFS, в ней по одной записи на каждый файл и папку. Запись хранит имя файла и его размеры, а также либо сами данные (у маленького файла), либо карту кластеров (у большого).

OVERLAPPEDЗадача 1

OVERLAPPED — структура, которую программа передаёт в ReadFile или WriteFile для асинхронного вызова. В ней лежат номер байта, с которого читать или писать, и событие hEvent, по которому Windows сообщает об окончании операции.

SlackЗадача 3

Slack — пустой хвост последнего кластера файла. Файл занимает кластер целиком, даже если его данные меньше кластера, поэтому остаток кластера принадлежит файлу, но данных в нём нет.

VCNЗадача 2

VCN (Virtual Cluster Number) — номер кластера внутри файла: первый кусок файла имеет VCN 0, второй — VCN 1, и так далее. VCN говорит, в каком порядке идут куски файла, а LCN — где каждый кусок лежит на диске.

Асинхронный вызовЗадача 1

Асинхронный вызов — вызов, после которого программа не ждёт, а сразу продолжает работу. Программа отдаёт операцию Windows и занимается своими делами, а Windows сообщает о готовности через событие hEvent. Пример из жизни: ты отправил письмо и пошёл дальше, а не стоишь у почтового ящика и не ждёшь ответа.

Блокировка потокаЗадача 4

Блокировка потока — остановка потока, пока не закончится операция. Поток — это одна линия выполнения программы: если поток читает большой файл синхронным вызовом, он стоит и ждёт, а программа на это время замирает.

КластерЗадачи 2, 3

Кластер — самый маленький кусок диска, который Windows выдаёт файлу, обычно 4096 байт. Файл всегда занимает целое число кластеров, даже если его данные меньше одного кластера. Пример: один кластер — это как одна полка: книгу тоньше полки всё равно кладут на целую полку.

Логический размерЗадача 3

Логический размер — сколько байт данных записано в файл. Это число показывает проводник в графе «Размер»: для файла из 2000 байт логический размер равен 2000.

Нерезидентный атрибутЗадача 2

Нерезидентный атрибут — часть записи MFT, которая не хранит сами данные файла, а хранит карту его кластеров. Так бывает у больших файлов: данные не помещаются в запись MFT и лежат на диске в кластерах.

Резидентный атрибутЗадача 2

Резидентный атрибут — часть записи MFT, в которой лежат сами данные файла. Так бывает у маленьких файлов: данные помещаются в запись MFT, и файл не занимает кластеров на диске.

Синхронный вызовЗадачи 1, 4

Синхронный вызов — вызов, после которого программа ждёт, пока операция закончится. Программа вызывает ReadFile и стоит, пока Windows не прочитает данные, и только потом идёт дальше. Пример из жизни: ты стоишь у кассы и ждёшь, пока кассир пробьёт товар, — уйти нельзя, пока он не закончит.

СмещениеЗадача 1

Смещение — номер байта в файле, с которого начинается чтение или запись. Смещение 0 — это самое начало файла, а смещение 4096 — байт номер 4096. Пример: как страница в книге — смещение говорит, с какого места читать.

Событие (hEvent)Задача 1

Событие (hEvent) — сигнал, которым Windows сообщает программе, что операция закончилась. Программа создаёт событие и кладёт его в OVERLAPPED, а когда Windows заканчивает чтение, она включает событие, и программа узнаёт, что данные готовы.

Физический размерЗадача 3

Физический размер (размер на диске) — сколько байт реально занято на диске под данные файла. Это число показывает проводник в графе «Размер на диске»: для файла из 2000 байт физический размер равен 4096, потому что файл занял один кластер.

Экстент (Data Run)Задача 2

Экстент (Data Run) — один непрерывный кусок файла на диске. У файла может быть несколько экстентов, если его кластеры лежат в разных местах диска, и каждый экстент описывается двумя числами: LCN, где кусок начинается, и VCN, какой это кусок по порядку.
