Словарь терминов лабораторной работы №3 в стиле ASD-STE100. Набор терминов и их порядок — те же, что в обычном словаре glossary.html.

Какие правила применены (примерно на 60%):

  • Одна мысль — одно предложение.
  • Описание — не больше 25 слов в предложении, инструкция — не больше 20 слов.
  • Действительный залог: пишется, кто что делает («Windows выделяет кластер», а не «кластер выделяется»).
  • Одно понятие — всегда одно и то же слово: «файл» — всегда «файл», «Windows» — всегда «Windows», без синонимов.
  • Сначала ответ, потом подробности: первое предложение — само определение.
  • Один абзац — одна тема, не больше шести предложений.

Что не применено: собственные имена функций из кода (ReadFile, DeviceIoControl, ERROR_HANDLE_EOF) оставлены как есть, названия граф проводника даны в кавычках, а вступление и этот список правил написаны обычным языком — правила действуют на сами определения.

$DATAЗадачи 2, 3

$DATA — это часть записи MFT, которая хранит данные файла. У маленького файла данные лежат в этой части. У большого файла эта часть хранит карту кластеров.

FSCTL_GET_RETRIEVAL_POINTERSЗадача 2

FSCTL_GET_RETRIEVAL_POINTERS — это команда, которая спрашивает у Windows карту кластеров файла. Программа посылает эту команду через DeviceIoControl. Windows отвечает списком экстентов. Если файл резидентный, Windows отвечает ошибкой ERROR_HANDLE_EOF.

IRPЗадача 4

IRP — это пакет, который описывает одну операцию с диском. Программа читает файл. Windows создаёт IRP. Windows передаёт IRP диску. Диск выполняет операцию. Диск возвращает IRP с результатом.

LCNЗадача 2

LCN — это номер кластера на диске. Windows нумерует кластеры тома подряд. Первый кластер имеет номер 0. LCN показывает, где на диске лежит кусок файла.

MFTЗадачи 2, 3

MFT — это главная таблица NTFS. MFT хранит одну запись для каждого файла. Запись хранит имя файла и размеры файла. У маленького файла запись хранит данные файла. У большого файла запись хранит карту кластеров.

OVERLAPPEDЗадача 1

OVERLAPPED — это структура для асинхронного вызова. Программа передаёт OVERLAPPED в ReadFile или WriteFile. OVERLAPPED хранит номер байта для чтения или записи. OVERLAPPED хранит событие hEvent. Windows сообщает через событие о конце операции.

SlackЗадача 3

Slack — это пустой хвост последнего кластера файла. Файл занимает кластер целиком. Данные файла меньше кластера. Остаток кластера принадлежит файлу. Данных в остатке нет.

VCNЗадача 2

VCN — это номер кластера внутри файла. Первый кусок файла имеет номер 0. Второй кусок файла имеет номер 1. VCN показывает порядок кусков файла. LCN показывает место куска на диске.

Асинхронный вызовЗадача 1

Асинхронный вызов — это вызов, который не ждёт конца операции. Программа отдаёт операцию Windows. Программа сразу продолжает работу. Windows сообщает о готовности через событие. Пример: человек отправляет письмо и идёт дальше.

Блокировка потокаЗадача 4

Блокировка потока — это остановка потока до конца операции. Поток — это одна линия выполнения программы. Поток читает большой файл. Поток ждёт конца чтения. Программа замирает на это время.

КластерЗадачи 2, 3

Кластер — это наименьшая единица диска для файла. Windows выдаёт файл кластерами. Обычно кластер равен 4096 байт. Файл занимает целое число кластеров. Данные файла меньше кластера. Файл всё равно занимает целый кластер.

Логический размерЗадача 3

Логический размер — это число байт данных в файле. Проводник показывает это число в графе «Размер». Файл из 2000 байт имеет логический размер 2000.

Нерезидентный атрибутЗадача 2

Нерезидентный атрибут — это часть записи MFT без данных файла. Эта часть хранит карту кластеров файла. Большие файлы имеют нерезидентный атрибут. Данные большого файла лежат на диске.

Резидентный атрибутЗадача 2

Резидентный атрибут — это часть записи MFT с данными файла. Маленькие файлы имеют резидентный атрибут. Данные маленького файла лежат в записи MFT. Файл не занимает кластеры на диске.

Синхронный вызовЗадачи 1, 4

Синхронный вызов — это вызов, который ждёт конца операции. Программа вызывает ReadFile. Программа ждёт, пока Windows прочитает данные. Потом программа продолжает работу. Пример: человек стоит у кассы и ждёт кассира.

СмещениеЗадача 1

Смещение — это номер байта в файле. Смещение показывает, где начинается чтение или запись. Смещение 0 показывает начало файла. Смещение 4096 показывает байт номер 4096.

Событие (hEvent)Задача 1

Событие — это сигнал о конце операции. Программа создаёт событие и кладёт событие в OVERLAPPED. Windows заканчивает чтение и включает событие. Программа проверяет событие. Программа узнаёт, что данные готовы.

Физический размерЗадача 3

Физический размер — это число байт на диске под данные файла. Проводник показывает это число в графе «Размер на диске». Файл из 2000 байт имеет физический размер 4096. Файл занял один кластер.

Экстент (Data Run)Задача 2

Экстент — это один непрерывный кусок файла на диске. Файл имеет один экстент или несколько экстентов. Кластеры файла лежат в разных местах диска. Каждый экстент имеет два числа. Первое число — это LCN. Второе число — это VCN.
