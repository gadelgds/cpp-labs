# Лабораторная работа №2 и Домашние задания (C++ & Win32 API)

В данной директории собраны все материалы, решения и теоретические разборы, разделенные по подпапкам в соответствии с их назначением:
* **`1_lab2_word/`** — Задания лабораторной работы №2 из файла Word.
* **`2_lecture_hw/`** — Домашнее задание с лекции (задачи с Фото 1 и 6 вопросов по ОС с Фото 3).
* **`3_practice_hw/`** — Домашнее задание на практику (4 задачи "Два из четырех наизусть" с Фото 2).

> **Мобильная версия шпаргалки**: Откройте [`index.html`](index.html) на телефоне или компьютере: минималистичный светлый дизайн, кнопки прямого копирования готового кода без комментариев и пошаговые объяснения каждого алгоритма.

├── 2_lecture_hw/               # ДЗ с лекции (Фото 1 и Фото 3)

## Особенности оформления кода
* Весь код в `.cpp` файлах очищен от объемных текстовых описаний — его можно сразу скопировать и вставить для сборки или сдачи.
* Все подробные пошаговые объяснения вынесены в файлы `README.md` внутри каждой подпапки и в интерактивный файл [`index.html`](index.html).
