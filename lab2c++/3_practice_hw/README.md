## Задача 1. Переменные (целые и действительные числа)

* **Исходный файл для копирования:** [`task1_vars_discount.cpp`](task1_vars_discount.cpp)

### Условие
Даны две переменные: `price` (цена товара, целое число в рублях) и `money` (купюра, которую дал покупатель, целое число). Посчитайте сдачу.
Дополнительно объявите переменную `discount` (скидка, действительное число, например `0.15` для 15%) и посчитайте цену со скидкой.

### Пошаговое объяснение решения
1. **Выбор типов данных:**
   * Переменные `price` и `money` имеют тип `int`, так как в условии сказано: "целое число в рублях".
   * Сдача `change = money - price` вычисляется как разность двух целых чисел и тоже имеет тип `int`.
   * Переменная `discount` имеет тип `double`, так как скидка представляет собой дробный коэффициент (например, $0.15 = 15\%$).
   * Итоговая цена со скидкой `discountedPrice` вычисляется умножением на дробь, поэтому объявляется типом `double`.
2. **Формула расчета цены со скидкой:**
   $$\text{discountedPrice} = \text{price} \times (1.0 - \text{discount})$$
   Например, при цене 350 руб. и скидке 0.15: $350 \times 0.85 = 297.5$ руб.
3. **Вывод в консоль:**
   Для красивого отображения денежных сумм используются манипуляторы `std::fixed` и `std::setprecision(2)` из библиотеки `<iomanip>`, что гарантирует вывод ровно двух знаков копеек после запятой.

## Задача 2. Преобразование типов (явное и неявное)

* **Исходный файл для копирования:** [`task2_type_casting.cpp`](task2_type_casting.cpp)

### Условие
Даны два целых числа: `int a = 7; int b = 3;`. Вычислите `a / b`.
Второй вариант: модифицируйте код с помощью явного приведения типов (`double`). Округлите результат до 3 знаков после запятой.

### Пошаговое объяснение решения
1. **Вариант 1 (Неявное целочисленное деление):**
   * Выражение `a / b` делит два числа типа `int`.
   * В C++ деление целых чисел всегда отбрасывает остаток (дробную часть): $7 / 3 = 2$ (остаток 1 отброшен).
2. **Вариант 2 (Явное приведение типов):**
   * Конструкция `static_cast<double>(a) / b` (или C-style `(double)a / b`) явно преобразует переменную `a` к типу `double`.
   * По правилам неявного продвижения типов в C++ (*usual arithmetic conversions*), если хотя бы один операнд деления имеет тип `double`, второй операнд `b` автоматически неявно приводится к `double`.
   * Деление выполняется как вещественное: $7.0 / 3.0 \approx 2.33333333...$
3. **Округление и вывод до 3 знаков после запятой:**
   * Вызов `std::fixed` переводит вывод чисел с плавающей точкой в форму с фиксированной точкой.
   * Вызов `std::setprecision(3)` задает отображение ровно трех знаков после точки: результат `2.333`.

## Задача 3. Посимвольное чтение строки

* **Исходный файл для копирования:** [`task3_char_reading.cpp`](task3_char_reading.cpp)

### Условие
Напишите программу, которая считывает текст из консоли по одному символу с помощью функции `getchar()` до тех пор, пока не встретит символ переноса строки (`'\n'`). Программа должна подсчитать и вывести, сколько пробелов было введено.

### Пошаговое объяснение решения
1. **Особенности функции `getchar()`:**
   * Функция `getchar()` (из `<cstdio>`) считывает один символ из стандартного потока ввода (`stdin`).
   * **Важно**: возвращаемый тип функции — `int`, а не `char`. Это необходимо для того, чтобы функция могла вернуть специальную отрицательную константу `EOF` (End of File, обычно `-1`) при ошибке или завершении ввода.
2. **Организация цикла:**
   * Конструкция `while ((ch = getchar()) != '\n' && ch != EOF)` считывает очередной символ, сохраняет его в переменную `ch` и проверяет, не равен ли он символу перехода на новую строку (нажатию клавиши Enter) или концу файла.
3. **Подсчет пробелов:**
   * Заводится счетчик `int spaceCount = 0;`.
   * Внутри цикла условие `if (ch == ' ')` увеличивает счетчик на 1 при обнаружении символа пробела (код ASCII 32).
4. **Вывод:**
   * После выхода из цикла печатается значение `spaceCount`.

## Задача 4. Преобразование числа в массив и конкатенация

* **Исходный файл для копирования:** [`task4_num_to_string.cpp`](task4_num_to_string.cpp)

### Условие
Есть строка `"Клиент №"`. Дано целое число `int ID = 245;`. Переведите это число в символьный массив с помощью функции `sprintf` (или `itoa`) и добавьте его в конец исходной строки, чтобы получилось `"Клиент №245"`.

### Пошаговое объяснение решения
1. **Резервирование памяти под строку:**
   * Исходный массив объявляется с запасом памяти: `char clientStr[128] = "Клиент №";`.
   * Если объявить массив размером ровно под фразу `"Клиент №"`, дописывание числа вызовет выход за границы массива (Buffer Overflow) и падение программы.
2. **Преобразование числа в строку:**
   * Создается промежуточный массив `char idStr[32];`.
   * Функция `sprintf(idStr, "%d", ID);` преобразует целое число 245 в символы `'2'`, `'4'`, `'5'` и автоматически добавляет завершающий нуль-терминатор `'\0'`.
   *(Альтернативный вариант: функция `_itoa(ID, idStr, 10);` переводит число в систему счисления с основанием 10).*
3. **Конкатенация строк (`strcat`):**
   * Функция `strcat(clientStr, idStr);` ищет завершающий нуль-терминатор в `clientStr` и копирует в его место символы из `idStr`, завершая строку новым `'\0'`.
4. **Результат:**
   * Строка `clientStr` содержит `"Клиент №245"`.
