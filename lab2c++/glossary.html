Словарь Словарь STE Теория по задачам Шпаргалка
Словарь объясняет термины лабы 2 простыми словами. Термины идут по алфавиту. У каждого термина указано, в какой задаче он встречается. Слова «программа», «переменная», «функция», «память» и «байт» используются как обычные слова — они не термины этой лабы.
Адрес памяти
термин 1 из 21
Определение

Адрес памяти — это номер ячейки в памяти компьютера.

Программа находит значение по этому номеру.

Пример из жизни: номер дома на улице — по нему находят сам дом.

Встречается в: 2_lecture_hw/task1_pointers.cpp, 1_lab2_word/task2_ptr_truncation_fix.cpp, 1_lab2_word/task3_kernel_handles.cpp

Буфер
термин 2 из 21
Определение

Буфер — это место в памяти, куда программа временно кладёт данные.

Пример: массив символов, в который sprintf записывает число перед склеиванием строки.

Встречается в: 3_practice_hw/task4_num_to_string.cpp, 3_practice_hw/task4b_move_letter_n.cpp

Венгерская нотация
термин 3 из 21
Определение

Венгерская нотация — это правило называть переменную так, чтобы её имя показывало её тип данных.

Пример: pszName — буквы psz означают «указатель на строку».

Встречается в: 1_lab2_word, задание 1 (теория, без кода)

getchar
термин 4 из 21
Определение

getchar — это функция, которая читает один символ с клавиатуры.

Пример: программа вызывает её в цикле и считает пробелы, пока не встретит конец строки.

Встречается в: 3_practice_hw/task3_char_reading.cpp

Модель данных
термин 5 из 21
Определение

Модель данных — это правило, которое задаёт размер каждого типа данных.

В Windows на x64 действует модель LLP64: long остаётся 4 байта, а указатель — 8 байт.

Пример: из-за этого в 64-битной программе нельзя класть адрес памяти в 32-битную переменную — он туда не помещается.

Встречается в: 1_lab2_word/task1_types_sizeof.cpp

Нуль-терминатор
термин 6 из 21
Определение

Нуль-терминатор — это ноль в конце строки.

Он показывает, где строка кончается.

Пример: в строке «Hello» пять букв и ноль в конце; без этого нуля программа не знает, где остановиться.

Встречается в: 2_lecture_hw/task2_strings_memory.cpp, 3_practice_hw/task4_num_to_string.cpp, 3_practice_hw/task4b_move_letter_n.cpp

Переполнение буфера
термин 7 из 21
Определение

Переполнение буфера — это запись данных за край буфера, в чужую память.

Программа после этого падает или портит соседние данные.

Пример: поэтому массив для строки всегда делают с запасом — например, 128 байт под короткое слово и число.

Встречается в: 3_practice_hw/task4_num_to_string.cpp, 3_practice_hw/task4b_move_letter_n.cpp

Префикс
термин 8 из 21
Определение

Префикс — это короткие буквы в начале имени переменной.

Префикс говорит, что за тип данных у переменной.

Пример: psz — строка, lp — указатель, h — хэндл, cb — число байт.

Встречается в: 1_lab2_word, задание 1 (теория, без кода)

Приведение типов
термин 9 из 21
Определение

Приведение типов — это перевод значения из одного типа данных в другой.

Пример: static_cast<double>(7) делает из целого 7 дробное 7.0, и деление 7 / 3 даёт 2.333 вместо 2.

Встречается в: 1_lab2_word/task2_ptr_truncation_fix.cpp, 3_practice_hw/task2_type_casting.cpp

Разыменование
термин 10 из 21
Определение

Разыменование — это получение значения по указателю.

Пример: запись *p означает «возьми значение, которое лежит по адресу памяти в p».

Встречается в: 2_lecture_hw/task1_pointers.cpp, 1_lab2_word/task2_ptr_truncation_fix.cpp

sizeof
термин 11 из 21
Определение

sizeof — это оператор, который сообщает размер типа данных или переменной в байтах.

Пример: sizeof(int) даёт 4, а sizeof(void*) в 64-битной программе даёт 8.

Встречается в: 1_lab2_word/task1_types_sizeof.cpp, 2_lecture_hw/task2_strings_memory.cpp

sprintf
термин 12 из 21
Определение

sprintf — это функция, которая записывает значение в строку.

Пример: sprintf(idStr, "%d", 245) кладёт символы «245» в массив.

Встречается в: 3_practice_hw/task4_num_to_string.cpp, 3_practice_hw/task4b_move_letter_n.cpp

strcat
термин 13 из 21
Определение

strcat — это функция, которая приклеивает одну строку к концу другой.

Пример: strcat("Клиент №", "245") даёт «Клиент №245».

Встречается в: 3_practice_hw/task4_num_to_string.cpp, 3_practice_hw/task4b_move_letter_n.cpp

Строка (C-строка)
термин 14 из 21
Определение

Строка — это ряд символов в памяти, который кончается нуль-терминатором.

Пример: «Hello» — это пять букв и ноль в конце.

Встречается в: 2_lecture_hw/task2_strings_memory.cpp, 3_practice_hw/task3_char_reading.cpp, 3_practice_hw/task4_num_to_string.cpp, 3_practice_hw/task4b_move_letter_n.cpp

Тип данных
термин 15 из 21
Определение

Тип данных — это правило, которое говорит, что за значения хранит переменная и сколько места они занимают.

Пример: int — целое число, 4 байта; double — дробное число, 8 байт.

Встречается в: 1_lab2_word/task1_types_sizeof.cpp, 1_lab2_word/task2_ptr_truncation_fix.cpp, 3_practice_hw/task2_type_casting.cpp

Указатель
термин 16 из 21
Определение

Указатель — это переменная, которая хранит адрес памяти, а не само значение.

Пример: int* p = &a — переменная p хранит адрес памяти переменной a.

Встречается в: 1_lab2_word/task1_types_sizeof.cpp, 1_lab2_word/task2_ptr_truncation_fix.cpp, 2_lecture_hw/task1_pointers.cpp, 2_lecture_hw/task2_strings_memory.cpp, 3_practice_hw/task4b_move_letter_n.cpp

Усечение указателя
термин 17 из 21
Определение

Усечение указателя — это потеря старшей половины адреса памяти при записи 64-битного указателя в 32-битную переменную.

Адрес памяти после этого ломается, и программа обращается не туда.

Пример: адрес 0x00007FF6A1B20000, записанный в 32-битную переменную, превращается в 0xA1B20000 — это уже другой адрес.

Встречается в: 1_lab2_word/task2_ptr_truncation_fix.cpp

Хэндл (дескриптор)
термин 18 из 21
Определение

Хэндл — это номер, который Windows выдаёт программе вместо прямого доступа к объекту ядра.

Программа называет номер, а Windows сама находит файл или событие.

Пример из жизни: номерок в гардеробе — по нему выдают пальто, а вешалку искать самому не нужно.

Встречается в: 1_lab2_word/task3_kernel_handles.cpp

Win32 API
термин 19 из 21
Определение

Win32 API — это набор готовых функций Windows.

Программа вызывает их, когда ей нужны файлы, события или память.

Пример: CreateFileW создаёт файл, CreateEventW создаёт событие.

Встречается в: Все задачи 1_lab2_word

x86 / x64
термин 20 из 21
Определение

x86 и x64 — это два вида процессоров и программ: x86 — 32-битный, x64 — 64-битный.

В программе x64 указатель занимает 8 байт, а в программе x86 — 4 байта.

Пример: поэтому один и тот же код на x64 и на x86 может давать разные числа в sizeof.

Встречается в: 1_lab2_word/task1_types_sizeof.cpp, 1_lab2_word/task2_ptr_truncation_fix.cpp

Ядро Windows
термин 21 из 21
Определение

Ядро Windows — это главная часть Windows.

Ядро управляет памятью, файлами и событиями.

Пример: программа не трогает файл напрямую, а просит ядро через хэндл.

Встречается в: 1_lab2_word/task3_kernel_handles.cpp
