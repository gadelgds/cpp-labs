Задание 1: 10 000 краткоживущих потоков — CreateThread против _beginthreadex

task1_createthread_vs_beginthreadex.cpp 
// Лабораторная работа №8, задание 1.
// Краткоживущие потоки: CreateThread против _beginthreadex.
// Сборка MSVC:  cl /EHsc task1_createthread_vs_beginthreadex.cpp psapi.lib
// Сборка MinGW: g++ -o task1.exe task1_createthread_vs_beginthreadex.cpp -lpsapi
// Запуск: task1.exe           — вариант CreateThread (по умолчанию)
//        task1.exe create     — то же, явно
//        task1.exe begin      — вариант _beginthreadex

#include <windows.h>
#include <process.h>   // _beginthreadex
#include <psapi.h>     // GetProcessMemoryInfo
#include <iostream>
#include <cstring>     // strtok, strcpy

// Сколько потоков создать всего.
const int THREAD_COUNT = 10000;
// Сколько раз strtok вызывается внутри одного потока.
const int STRTOK_CALLS = 100;

// Тестовая строка для strtok. strtok портит строку,
// поэтому каждый поток работает со своей копией.
const char* TEST_STRING = "один,два,три;четыре пять:шесть";

// Функция потока: многократно разбирает копию тестовой строки.
DWORD WINAPI WorkerThread(LPVOID /* param */)
{
    char buffer[128];
    for (int i = 0; i < STRTOK_CALLS; ++i) {
        // Свежая копия: strtok ставит '\0' вместо разделителей.
        // Буфер 128 байт, тестовая строка намного короче.
        strcpy(buffer, TEST_STRING);
        // Первый вызов — с указателем на строку.
        char* token = strtok(buffer, ",;: ");
        // Дальше — с NULL: продолжаем разбор той же строки.
        while (token != nullptr) {
            token = strtok(nullptr, ",;: ");
        }
    }
    return 0;
}

// Печатает текущее потребление памяти процесса.
// PrivateUsage — память, занятая только этим процессом (то, что
// видно в диспетчере задач как Private Bytes в столбце "Память").
// WorkingSetSize — память, реально находящаяся в ОЗУ сейчас.
void PrintMemory(const char* label)
{
    PROCESS_MEMORY_COUNTERS_EX pmc;
    if (GetProcessMemoryInfo(GetCurrentProcess(),
            reinterpret_cast<PROCESS_MEMORY_COUNTERS*>(&pmc), sizeof(pmc))) {
        std::cout << label
                  << "  WorkingSet: " << pmc.WorkingSetSize / 1024 << " КБ"
                  << "  PrivateUsage: " << pmc.PrivateUsage / 1024 << " КБ"
                  << std::endl;
    }
    else {
        std::cout << label << "  (не удалось прочитать память, код "
                  << GetLastError() << ")" << std::endl;
    }
}

int main(int argc, char* argv[])
{
#if defined(_WIN32)
    system("chcp 65001 > nul"); // Русский текст в консоли без кракозябр.
#endif

    // Выбор варианта по аргументу командной строки.
    bool useBeginThreadEx = (argc > 1 && strcmp(argv[1], "begin") == 0);

    std::cout << "=== ЗАДАНИЕ 1: CreateThread против _beginthreadex ===" << std::endl;
    std::cout << "Вариант: "
              << (useBeginThreadEx ? "_beginthreadex" : "CreateThread")
              << std::endl;
    std::cout << "Потоков к созданию: " << THREAD_COUNT << std::endl;
    PrintMemory("Старт:   ");

    for (int i = 0; i < THREAD_COUNT; ++i) {
        HANDLE hThread = nullptr;

        if (useBeginThreadEx) {
            // _beginthreadex: поток с инициализацией CRT.
            // Сигнатура WorkerThread приводится к типу _beginthreadex.
            uintptr_t h = _beginthreadex(
                nullptr, 0,
                reinterpret_cast<unsigned (__stdcall*)(void*)>(WorkerThread),
                nullptr, 0, nullptr);
            hThread = reinterpret_cast<HANDLE>(h);
        }
        else {
            // CreateThread: «голый» поток Windows без CRT-состояния.
            hThread = CreateThread(
                nullptr, 0, WorkerThread, nullptr, 0, nullptr);
        }

        if (hThread == nullptr) {
            std::cout << "Ошибка создания потока №" << i
                      << ", код " << GetLastError() << std::endl;
            return 1;
        }

        // Ждём завершения потока и закрываем его дескриптор.
        WaitForSingleObject(hThread, INFINITE);
        CloseHandle(hThread);

        // Каждую тысячу потоков — срез памяти, чтобы видеть рост.
        if ((i + 1) % 1000 == 0) {
            std::cout << "Создано потоков: " << (i + 1) << "  ";
            PrintMemory("");
        }
    }

    std::cout << "Создано потоков всего: " << THREAD_COUNT << std::endl;
    PrintMemory("Финиш:  ");
    std::cout << "Сравните PrivateUsage на старте и на финише." << std::endl;
    std::cout << "С CreateThread PrivateUsage заметно растёт, "
              << "с _beginthreadex — почти не меняется." << std::endl;

    return 0;
}

Как запустить
  1. Скомпилировать. MSVC (Developer Command Prompt): cl /EHsc task1_createthread_vs_beginthreadex.cpp psapi.lib — получится task1_createthread_vs_beginthreadex.exe. MinGW: g++ -o task1.exe task1_createthread_vs_beginthreadex.cpp -lpsapi.
  2. Запустить вариант CreateThread: task1.exe или task1.exe create.
  3. Запустить вариант _beginthreadex: task1.exe begin.
  4. Как смотреть Private Bytes в диспетчере задач: Ctrl+Shift+Esc → вкладка «Подробности» → правый клик по заголовкам столбцов → «Выбрать столбцы» → включить «Память (активный частный рабочий набор)» / «Выделенная память» (Private Bytes зависит от версии Windows) → найти процесс task1.exe и следить за столбцом во время работы программы. Столбец «Память» по умолчанию показывает рабочий набор (Working Set), а не Private Bytes — для задания нужен именно частный набор.
  5. Программа и сама печатает память: строки «Старт», каждые 1000 потоков и «Финиш» — WorkingSet и PrivateUsage в килобайтах.
Ожидаемый вывод (вариант CreateThread): «Вариант: CreateThread» → «Старт: WorkingSet: … PrivateUsage: …» → каждые 1000 потоков PrivateUsage заметно растёт (на тысячи килобайт к концу) → «Создано потоков всего: 10000» → «Финиш: PrivateUsage» заметно больше стартового. Вариант _beginthreadex: те же строки, но PrivateUsage почти не меняется от старта к финишу. Точные числа зависят от ПК.
Задание 2: Приостановленный поток и перехват через RIP

task2_suspended_hook.cpp 
// Лабораторная работа №8, задание 2.
// Приостановленный поток (CREATE_SUSPENDED) и перехват через RIP.
// Сборка MSVC:  cl /EHsc task2_suspended_hook.cpp
// Сборка MinGW: g++ -o task2.exe task2_suspended_hook.cpp
// Запуск: task2.exe

#include <windows.h>
#include <iostream>

// Номер Фибоначчи для расчёта. Fib(40) рекурсивно —
// около 100 миллионов вызовов, это занимает несколько секунд:
// расчёт достаточно тяжёлый, чтобы поток был «настоящей работой»,
// а не мгновенным действием.
const int FIB_N = 40;

// Сюда хук запишет результат расчёта.
long long g_result = -1;

// Рекурсивное вычисление чисел Фибоначчи.
// Медленно, но наглядно: каждый вызов порождает два новых.
long long FibRecursive(int n)
{
    if (n <= 1) return n;
    return FibRecursive(n - 1) + FibRecursive(n - 2);
}

// Оригинальная функция потока: то, с чего поток должен был стартовать.
// Если перехват сработал, эта функция НЕ выполнится ни разу —
// её сообщение на экране не появится. Это и есть доказательство.
DWORD WINAPI FibThread(LPVOID /* param */)
{
    std::cout << "ОРИГИНАЛ: поток стартовал со своей функции FibThread."
              << std::endl;
    g_result = FibRecursive(FIB_N);
    std::cout << "ОРИГИНАЛ: Fib(" << FIB_N << ") = " << g_result
              << std::endl;
    return 0;
}

// Функция-перехватчик (хук). Поток стартует с неё вместо FibThread:
// мы подменили регистр RIP в контексте потока до его запуска.
// Получает тот же параметр, что и оригинальная функция потока.
DWORD WINAPI HookThread(LPVOID /* param */)
{
    std::cout << "ПЕРЕХВАТ: поток стартовал с хука HookThread, "
              << "а не с FibThread!" << std::endl;
    std::cout << "ПЕРЕХВАТ: выполняю расчёт Fib(" << FIB_N << ")..."
              << std::endl;
    g_result = FibRecursive(FIB_N);
    std::cout << "ПЕРЕХВАТ: Fib(" << FIB_N << ") = " << g_result
              << std::endl;
    return 0;
}

int main()
{
#if defined(_WIN32)
    system("chcp 65001 > nul"); // Русский текст в консоли без кракозябр.
#endif

    std::cout << "=== ЗАДАНИЕ 2: CREATE_SUSPENDED + перехват через RIP ==="
              << std::endl;
    std::cout << "Расчёт: Fib(" << FIB_N << ") рекурсивно." << std::endl;

    // Создаём поток ПРИОСТАНОВЛЕННЫМ: он не выполнит ни одной
    // инструкции, пока мы не вызовем ResumeThread.
    HANDLE hThread = CreateThread(
        nullptr, 0, FibThread, nullptr, CREATE_SUSPENDED, nullptr);
    if (hThread == nullptr) {
        std::cout << "Ошибка CreateThread: " << GetLastError() << std::endl;
        return 1;
    }
    std::cout << "Поток создан с CREATE_SUSPENDED и пока спит." << std::endl;

    // Готовим структуру контекста. ContextFlags говорит системе,
    // какие регистры нам нужны: CONTEXT_FULL — все основные регистры,
    // включая RIP. Без этого флага GetThreadContext вернёт мусор.
    CONTEXT ctx;
    ZeroMemory(&ctx, sizeof(ctx));
    ctx.ContextFlags = CONTEXT_FULL;

    // Читаем контекст приостановленного потока.
    // На работающем потоке это делать нельзя — контекст «плывёт».
    if (!GetThreadContext(hThread, &ctx)) {
        std::cout << "Ошибка GetThreadContext: " << GetLastError()
                  << std::endl;
        CloseHandle(hThread);
        return 1;
    }

#ifdef _WIN64
    std::cout << "Исходный RIP потока: 0x" << std::hex << ctx.Rip
              << std::dec << std::endl;
    // Подмена точки входа: поток начнётся с хука, а не с FibThread.
    // На x64 регистр называется RIP (на x86 был бы EIP).
    ctx.Rip = reinterpret_cast<DWORD64>(HookThread);
    std::cout << "Новый RIP потока:    0x" << std::hex << ctx.Rip
              << std::dec << " (адрес HookThread)" << std::endl;
#else
    std::cout << "Исходный EIP потока: 0x" << std::hex << ctx.Eip
              << std::dec << std::endl;
    ctx.Eip = reinterpret_cast<DWORD>(HookThread);
    std::cout << "Новый EIP потока:    0x" << std::hex << ctx.Eip
              << std::dec << " (адрес HookThread)" << std::endl;
#endif

    // Записываем изменённый контекст обратно в поток.
    if (!SetThreadContext(hThread, &ctx)) {
        std::cout << "Ошибка SetThreadContext: " << GetLastError()
                  << std::endl;
        CloseHandle(hThread);
        return 1;
    }
    std::cout << "Контекст изменён: поток стартует с хука." << std::endl;

    // Оживляем поток: теперь он выполнит первую инструкцию
    // уже по новому адресу — из HookThread.
    DWORD prevSuspend = ResumeThread(hThread);
    std::cout << "ResumeThread вызван (счётчик приостановки был "
              << prevSuspend << "). Поток работает..." << std::endl;

    // Ждём, пока поток закончит расчёт.
    WaitForSingleObject(hThread, INFINITE);
    CloseHandle(hThread);

    std::cout << "Поток завершён. Итог: Fib(" << FIB_N << ") = "
              << g_result << std::endl;
    if (g_result == 102334155) {
        std::cout << "Результат верный: Fib(40) = 102334155." << std::endl;
    }
    std::cout << "Доказательство перехвата: сообщение «ПЕРЕХВАТ» есть, "
              << "а сообщение «ОРИГИНАЛ» не появилось — FibThread "
              << "так и не запустилась." << std::endl;

    return 0;
}

Как запустить
  1. Скомпилировать. MSVC (Developer Command Prompt): cl /EHsc task2_suspended_hook.cpp — получится task2_suspended_hook.exe. MinGW: g++ -o task2.exe task2_suspended_hook.cpp.

  3. Программа работает только на x64 (используется RIP; на x86 — ветка с EIP). Сборка должна быть 64-битной: MSVC — командная строка x64, MinGW — mingw64.
  4. Расчёт Fib(40) рекурсивно занимает несколько секунд — это нормально, дождитесь завершения программы.
Ожидаемый вывод: «Поток создан с CREATE_SUSPENDED и пока спит.» → «Исходный RIP потока: 0x…» → «Новый RIP потока: 0x… (адрес HookThread)» → «Контекст изменён: поток стартует с хука.» → «ПЕРЕХВАТ: поток стартовал с хука HookThread, а не с FibThread!» → «ПЕРЕХВАТ: Fib(40) = 102334155» → «Поток завершён. Итог: Fib(40) = 102334155» → «Результат верный: Fib(40) = 102334155.» Сообщение «ОРИГИНАЛ» не появляется ни разу — это и есть доказательство перехвата.
Если в выводе появилось «ОРИГИНАЛ: поток стартовал со своей функции FibThread.» — перехват не сработал: проверьте, что SetThreadContext вызван до ResumeThread и что ContextFlags = CONTEXT_FULL.
