# Лабораторные работы по C++ и Win32 API

Репозиторий с практическими заданиями, исходным кодом и теоретическими материалами по курсу системного программирования на C++ и Windows API.

## Структура репозитория

```text
c++/
├── .gitignore
├── README.md
├── 2 10.03 Лаб_Cpp__L2___stud_cut.docx  # Исходное методическое задание
├── photo_*.jpg                          # Материалы и экзаменационные вопросы
└── lab2c++/                             # Лабораторная работа №2
    ├── index.html                       # Мобильная веб-шпаргалка с разбором
    ├── README.md                        # Методичка и описание решений
    ├── task1_pointers.cpp               # Задача 1: Операции с указателями
    ├── task2_strings_memory.cpp         # Задача 2: Память строк и массивов
    ├── task3_vars_discount.cpp          # Задача 3: Переменные, сдача и скидка
    ├── task4_type_casting.cpp           # Задача 4: Приведение типов a/b
    ├── task5_char_reading.cpp           # Задача 5: Посимвольное чтение через getchar()
    ├── task6_num_to_string.cpp          # Задача 6: Число в строку (sprintf / itoa)
    ├── task7_win32_types_sizeof.cpp     # Задача 7: Модели данных Win32 (sizeof)
    ├── task8_ptr_truncation_fix.cpp     # Задача 8: Фикс усечения указателя в x64
    └── task9_kernel_handles.cpp         # Задача 9: Хэндлы объектов ядра Windows
```

## Лабораторные работы

* [Лабораторная работа №2](lab2c++/) — Типы данных Win32, модели памяти x86/x64, указатели, строки, объекты ядра Windows, асинхронный ввод-вывод и устройство NTFS.

## Требования для сборки
* Компилятор C++ с поддержкой C++11 и выше (MSVC 2019/2022 или MinGW-w64 g++).
* Операционная система Windows (для задач, использующих `<windows.h>`).
