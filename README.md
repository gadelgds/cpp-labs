# Лабораторные работы по C++ и Win32 API

Репозиторий с практическими заданиями, исходным кодом и теоретическими материалами по курсу системного программирования на C++ и Windows API.

## Структура репозитория

```text
c++/
├── .gitignore
├── README.md
├── 2 10.03 Лаб_Cpp__L2___stud_cut.docx  # Исходное задание к лабораторной работе №2
├── photo_*.jpg                          # Фотографии задач и лекционных вопросов
└── lab2c++/                             # Лабораторная работа №2 и домашние задания
    ├── index.html                       # Мобильная веб-шпаргалка с разбором и кнопками копирования
    ├── README.md                        # Навигация по работе
    │
    ├── 1_lab2_word/                     # Задания из Word-файла (Лабораторная работа №2)
    │   ├── README.md                    # Полный разбор теории, венгерская нотация, таблицы
    │   ├── task1_types_sizeof.cpp       # Размеры типов данных в x86 и x64
    │   ├── task2_ptr_truncation_fix.cpp # Исправление ошибки усечения адреса в x64
    │   └── task3_kernel_handles.cpp     # Объекты ядра Windows и псевдо-дескрипторы
    │
    ├── 2_lecture_hw/                    # Домашнее задание с лекции (Фото 1 и Фото 3)
    │   ├── README.md                    # Разбор задач и 6 экзаменационных вопросов по ОС
    │   ├── task1_pointers.cpp           # Базовые операции с указателями
    │   └── task2_strings_memory.cpp     # Память строк и массивов (sizeof в x64)
    │
    └── 3_practice_hw/                   # Домашнее задание на практику (Фото 2: «2 из 4 наизусть»)
        ├── README.md                    # Пошаговые объяснения всех 4 алгоритмов
        ├── task1_vars_discount.cpp      # Переменные, сдача и расчет скидки
        ├── task2_type_casting.cpp       # Приведение типов a / b и double (3 знака)
        ├── task3_char_reading.cpp       # Посимвольное чтение через getchar()
        └── task4_num_to_string.cpp      # Перевод числа в строку (sprintf / itoa)
```

## Добавление будущих лабораторных работ
Структура корневой папки `c++` позволяет в дальнейшем легко добавлять следующие лабораторные работы (`lab3c++`, `lab4c++` и т.д.) отдельными папками и коммитить их в этот репозиторий.
